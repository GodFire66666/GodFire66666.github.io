# Personal Blog

A static personal blog built with Astro and Markdown, ready for GitHub Pages.

Live site: https://godfire66666.github.io

## Local development

```bash
npm install
npm run dev
```

Site metadata lives in `src/config.ts`. Posts live in `src/content/posts/`,
with one Markdown file per post.

Pushing to `main` triggers GitHub Actions to build and publish the site.
